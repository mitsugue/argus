# 所有者の対話と仮定の根拠処理

13.6要件の対話用計算・文脈モジュールを実装した。現時点では純粋関数の検証までで、
対話API・画面・実GPT応答・保存・遠隔復旧は未接続。対話を利用可能とは報告しない。
既存の市場6点説明・数値と参照IDの検証を再利用し、判定エンジンの権限は変更しない。

## 分離する情報

- サーバーから解決した市場文脈のIDと指定した期間。別期間の指数価格経路は混ぜない。
- 所有者が申告した保有状態、数量、取得単価、購入理由、保有期間。取引所で検証した事実とは扱わない。
- 質問と会話上の仮定。実測値・実際の保有・正式な予測履歴の更新権限は持たない。
- 前の対話は同じ対象・市場・期間で、保存内容のハッシュが一致する場合だけ比較に使う。

入力は指定フィールドのみ、対象不一致・負の数量・保有状態との矛盾・未来の申告時刻は拒否する。
所有者文脈はOWNER_PRIVATEで、公開市場のキャッシュや公開履歴に追加しない。
日本株と米国株を分ける。米国株は日本株の信用条件・価格経路を適用せず、
現在の個別米国株計算の不足を明記する。世界共通のニュース・予定も対象への影響と事実を混同しない。

## 計算できる仮定

FX_TRANSLATIONは「円建て日経平均が変わらない」という明示条件と、指定したUSD/JPYで
現物指数をドル換算するだけ。為替の変化から日本株の騰落や海外投資家の注文を推定しない。
EPS_MULTIPLEは、指数定義が整合すると検証された公表EPSと、指定したPERの積だけ。
価格÷PERから逆算したEPSは公表EPSとして利用しない。特定倍率を天井として採用しない。
どちらも入力の原典ハッシュ・観測・受信時刻が確認できなければ数値を出さない。
EPSの本番原典接続は未完了で、この算式の実装をデータ接続済みと呼ばない。

仮定を引用する回答は「仮定」と明記した推論に限定する。過去の仮定を後の会話で引用しても
実測事実へ昇格しない。割合や価格をLLMに作らせず、計算結果と参照された根拠だけを使う。
元の見立てへ戻すUIとチャート反映は後続接続の対象。

## 次の接続条件

既存OWNER_SYNC認証を使う所有者用経路として対話APIを実装する。匿名の生成APIは作らない。
サーバー側で市場文脈・指数・EPSを解決し、クライアントの市場数値や検証済みフラグを信頼しない。
本人申告だけをクライアントから受け取り、質問・本人申告内の指示をシステム命令として扱わない。
既存のGPT呼出しと機能別使用量記録を接続し、公開6点説明と同じ根拠から回答する。
リクエストIDによる二重実行抑止、保存の読戻し、履歴と遠隔復旧、実ブラウザ・iPhone受入まで続ける。
13.6全体の本番受入・運用点検後に停止し、13.7は明示的再開まで保留する。
