# 日経平均の比較履歴の接続修正

2026-09-16。本番13.7.11の5営業日比較を読み取り確認したところ、価格487営業日、
営業日表2026-01-05以降、検索可能131局面、選択2026-07-21・2026-04-02だった。
既存約10年のETF研究と、日経平均そのものの比較入力は別であり、前者の存在を
後者の接続完了と扱ってはいけない。

## 今回の変更

- 日経平均の既存価格を再利用し、不足する過去側だけを最大10年・3000足に限定して取得する。
- 公式営業日表を同期間で照合する。価格がある日を営業日表の代用にせず、欠損窓は除外する。
- `n225_analog_inputs.json`を既存永続領域へ原子的に保存し、内容ハッシュと読み戻しを検証する。
  起動後は保存履歴を復元する。直近価格は小さな訂正窓で更新し、長い取得中断時は既存2年経路で補う。
- 過去側の初期取得に成功した後は通常更新で繰り返さない。失敗時も同日中の連続再取得を抑制する。
  営業日表は新しい日と直近7日の訂正窓だけを更新する。
- 計算・候補の選択式は維持する。最大3候補、年別割当なし、その後の成績による選択なし。
- 画面/APIに価格収録期間、検索できた局面の期間・年別件数、欠損による除外を表示する。
  過去10年に全需給指標がそろうことや、予測力の実証を意味しない。

公開チャートは既存の保存済み計算結果を読む。画面表示による全期間取得・全計算・LLM呼出しは行わない。
収集側の特徴量計算は入力内容と日付が同じなら再利用するが、変更時の全期間リプレイの差分化は未完了。
過去の当時公表版は未検証。今回の取得成功で検証済み確率や売買権限へ昇格させない。

## 証跡と未完了

公式営業日APIは2016-09-16から2026-09-16まで3653暦日を返した。
日経平均の不足期間の取得も成功したが、これは原典取得の確認であり本番接続の完了ではない。
実装・対象テスト・ビルドの証跡は保存する。本番の新しい候補数・期間、永続読み戻し、
実画面の線と説明、反復GET時の追加取得ゼロは配信後の確認事項。
旧判断履歴・既存研究成果は削除せず、旧比較計算を新しい結果に書き換えない。
