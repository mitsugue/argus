# 日経平均の円換算と入力の改訂

13.6の価格尺度接続。仕様・実装・実データ検証・本番受入を区別する。

日経公式の日次サマリーの「日経平均株価」と「株価収益率(PER)／指数ベース」を
同じ日付から取得する。加重平均PER、PBR、ETFのPERを代入しない。
EPSは同日の指数終値÷指数ベースPERからの逆算値で、独立した公表EPSではない。
公表時刻は不明として保持し、実際の取得完了時刻より前の判断には使わない。
この履歴から過去に公表されていた数値を再現できたとは扱わない。

過去比較の形状に現在の指数EPS×現在の指数PERを掛け、円建て指数値へ換算する。
この積は基準の指数価格に一致する。PER帯による切捨ては行わず、類似候補の選択も変えない。
利益成長や倍率の将来変化を別途予測する方式とは区別する。予測確率・BUYの権限は追加しない。

既存収集処理からのみ取得する。公開閲覧・会話の参照では通信も保存も行わない。
1応答256KiB、25秒の処理期限、正常時30分／失敗時5分の間隔を設ける。
これは通信処理の有界性と重複抑制であり、AIの費用制限ではない。
取得失敗時は前回の値と時点を保持する。日付・指数価格・時点がチャートの基準と
一致しない場合は形状比較を継続し、古いPERで新しい価格を換算しない。

永続領域のSQLiteに入力改訂を追記し、同じ値の再取得では最初の取得時点を維持する。
訂正や元の値への再変更も別の改訂として残す。削除や過去の上書きは行わない。
チャート、統合AIの期間別根拠、既存の判断履歴に同じ入力・式・出典ハッシュを保存する。
遠隔復旧は保存された判断履歴に含む入力と、取得器自身のSQLite復旧を分けて評価する。

実装済み：固定原典の取得、時点検証、追記保存、読み戻し、円換算、尺度の説明、
同じ計算入力からの統合AI根拠生成。ローカル実データと390px／1280pxブラウザで確認済み。
本番収集・実GPT回答・本番履歴の改訂・別ホストの入力DB復旧・iPhoneは未受入。
独立した公表EPS系列、EPS成長の予測、有効性の独立検証は、この接続によって完了とはしない。
13.7には着手しない。
