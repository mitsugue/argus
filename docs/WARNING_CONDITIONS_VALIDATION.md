# 日本株の警戒条件の接続と成績

本変更は実装候補。本番の入力範囲・保存・表示の受入は別に確認する。
成立件数を暴落警戒度や確率にしない。BUY・注文には接続しない。

①二市場の信用売り残8,000億円未満、②1570の制度信用倍率1倍以上、
⑤海外投資家の売り越し、⑥VIXのMACD差が正（12・26・9）は、現在の規則で
独立して成績を測る。⑤の買い越し・⑥のMACD差が負を使う旧支援条件の成績を流用しない。
⑤のゼロは警戒成立でなく、売り越し状態の反転を買い越し状態の単純反転から作らない。

既存の入力と計算済み履歴を読み、最初に利用できた改訂版を使う。未来の公表・受領時刻を
除き、当時より古い期間の遅着を最新状態の変化にしない。価格は公式の東京営業日と、
確定した日経平均終値を使う。新しい取得・AI呼び出し・並列の履歴保存基盤は作らない。
出来事を知った日本日付の次の営業日終値から5・20営業日後の騰落を測り、20営業日以内の
重複をまとめる。通常時の下落割合と同じ対象期間で比較し、時系列の後半で差を点検する。

成立後の下落件数、採点件数、件数不足・通常時を上回るかの測定結果を各項目へ表示する。
件数が増えても自動で「検証済み」にならない。取得した過去データが当時の保存原本ではない
制約を残し、予測力の認定・将来の確率・原典の予測実績とは区別する。
異なる規則・時点・改ざんされた成績は採用しない。

③は現物の日経平均とS&P500の既存キャッシュを優先して説明し、ETF比較は現物が不足した
場合に別の代理値として残す。同じ日付の後から閉じる米国市場を東京の判断へ先取りしない。
20営業日相対騰落率と指数比を区別する。④は現行の時価総額加重の推計EPSを維持する。
③④⑦の警戒数値規則はオーナーの判断待ちで、測定値があっても未定義の条件を点灯させない。
⑦の好決算の集合・最低件数・反応期間は未作成。原典の説明や研究仮説を確定した規則と呼ばない。

画面の7条件の判定状況は、成立・未成立として測定できた件数、基準未確定の番号、
更新待ち・欠測の各入力を分ける。登録銘柄・他の分析データのPARTIALは別の折りたたみ欄とし、
7条件の完成度として流用しない。判定基準未確定を「再取得すれば直る」と表示しない。
②の成績は制度信用の買残・売残の原入力を使い、比率だけの表示配列や総信用の倍率を使わない。
現在倍率も両側の利用可能時刻の遅い方を採用し、片側の先の時刻にさかのぼらない。

⑦の下準備では、既存の配当用銘柄別取得と決算の日付別取得の応答を再利用する。
営業利益・通期営業利益予想・翌事業年度予想・対象年度・開示日時を既存の
非公開 `jp_market_source_history.sqlite3` に追記し、受領時刻・原内容のハッシュを残す。
公式仕様は [財務情報の定義](https://jpx-jquants.com/ja/spec/fin-summary) を使い、空欄をゼロ・据え置きと見なさない。
異なる内容の訂正は別の観測として保全する。同じ応答を重複保存せず、今日の取得を
当時の受領記録と偽らない。日付別の成功した空応答と未取得を分ける。
現在と過去の構成銘柄候補を保持するが、日経225への採用は対象日の構成判定が別途必要。
取得・保存の状態だけを診断へ渡し、契約データの本文は公開の検査・配布物・説明履歴へ出さない。
この入力保存は、⑦の好決算判定・価格反応・規則採用・成績の完成を意味しない。
