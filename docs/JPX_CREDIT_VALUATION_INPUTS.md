# 公式信用データから計算する評価損益率

`argus_jpx_credit_valuation` は、JPXの信用取引現在高から二市場合計の六入力を読み、用語集掲載の日経の算式を計算する。入力と計算を検査し、既存台帳の保存・読み戻し、D01への受け渡し、既存の定期取得への接続を実装・検査した。実データの本番保存と自然な定期実行の確認は別に行い、コードだけで接続完了とはしない。

## 算式と単位

買い残高金額をB、社内対当株数をM、貸借融資と自己融資の株数合計をS、同金額合計をFとし、`((F / S) * M + F - B) / B * 100` を使う。金額は百万円、株数は千株。画面向けの符号は評価損が負、評価益が正で、JPX用語集の符号と反対。公式に公表された評価損益率そのものではなく、公式入力からARGUSが算式で計算した値として扱う。

算式出典: https://www.jpx.co.jp/glossary/ha/387.html
週次出典: https://www.jpx.co.jp/markets/statistics-equities/margin/04.html
月報出典: https://www.jpx.co.jp/markets/statistics-equities/monthly/index.html

## 読み取りと欠測

- 旧xlsと新xlsxは、それぞれの見出し・単位・株数行・金額行を照合する。東京のみ、貸株側、前週差を融資入力へ混ぜない。
- 月報は二市場の22列ブロックのみを読み、役割見出しの順、年、月、日、全数値列を検査する。元号併記、西暦のみ、12月から1月の年またぎに対応する。
- 未公表を表す `-` はゼロにしない。必要な六入力が欠けた週は値を `None` とし、欠けた入力名を残す。他の週を補間しない。
- 欠列、見出し順変更、日付逆転、重複日付、非有限値、負の残高、ゼロ分母は拒否する。
- 計算前の六入力・手法版・単位・符号・出典を保持し、表示用丸めは読み取り段階では行わない。

## 検証状態

新旧週次の実資料5週と照合点を検査済み。月報43冊の735行をローカルで照合し、重複掲載を含む546週、2016年以降541週を復元した。重複掲載の六入力に相違なし。2019年7月12日は資料が融資情報を非公表としており欠測で保持。実資料と実取得記録は公開リポジトリへ保存していない。

現在取得した月報から当時の公表・受信時刻を作らない。`historicalVintageVerified=False` を残す。期間末から5暦日後の価格で測る比較は研究上の仮定であり、当時の情報だけを使った実運用成績とはしない。「売り残8,000億円未満と評価損益率−10%以下」だけの比較を、悪材料・買い残最高などを含む原典の完全な条件の検証と呼ばない。予測確率・売買権限を与えない。

## 本番接続の確認条件

1. 既存の週次収集と同じ台帳へ、対象週・公式公表時刻の確認状況・実取得時刻・六入力・計算値を保存する。独立した恒久台帳は作らない。
2. 旧 `manual_csv` / `licensed` の保存済み記録を保持し、今回の公式入力からの計算値と行単位で区別する。シリーズ全体の分類を変更して旧保護データを公開しない。
3. `LICENSE_BLOCKED` の解除は新しい取得経路と入力検査を確認してから行い、計算処理が存在するだけで本番接続済みとしない。
4. 自然な定期実行の保存と認証された読み戻しを確認する。2026年10月2日週の自動保存は2026年10月6日の公表後に確認する。

## 台帳の保存と表示の契約

同じ `credit.valuation_loss_pct` へ追記し、元の `manual_csv` / `licensed` の記録とシリーズの保護方針を維持する。新しい計算行は六入力から再計算し、値・符号・単位・出典・取得時刻を検査してから受け入れる。JSONの監査情報は16KiB・32項目以内のオブジェクトとして扱う。異常時に台帳を変更しない。

公式公表時刻は未確認のまま保存し、実取得時刻からだけ利用可能にする。現在取得した月報の過去行を、当時の分析へ紛れ込ませない。融資入力の非公表は値を作らず、欠けた入力を残す。

表示には監査を通った計算行だけを使い、旧保護行を履歴・前週差・順位へ混ぜない。六入力は全観測に保存し、画面応答には最新の監査情報と各週の照合ハッシュを同梱する。これらの準備・検査の合格を、定期保存・本番接続の完了とみなさない。

## 分析入力の受け渡し

台帳の公式六入力の検査を通った行だけを、既存の信用売り残・買い残と同じD01入力に渡す。旧manual/licensed行をこの新経路へ自動移行しない。D01の売り残の条件・感応度候補・未検証状態・判断権限は変更しない。これは入力接続の準備であり、自然な収集・保存・読み戻しの本番確認とは区別する。


## 定期取得への接続（13.8.49）

既存の信用残取得ジョブで同じ公式Excelの六入力から評価損益率を計算し、既存のmarket-ledgerへ保存する。信用残の最新週と監査済み評価損益率の最新週は独立に確認し、評価損益率の補完だけで保存済みの信用残を再取り込みしない。値・実取得時刻・六入力の内容ハッシュを、送信したすべての週について認証された読取りで照合する。欠けた週や一致しない根拠があれば完了としない。

旧CSVではmetadata欄は任意のまま。新しい計算行には六入力・出典のハッシュ・実取得時刻をJSONで含める。取得済み週は再送せず、保護された応答・元Excel・台帳値を公開の実行ログや成果物へ出さない。月報の長期履歴と当時の利用可能時点の証明は別の残件であり、この定期接続だけで10年分の本番接続完了とはしない。
