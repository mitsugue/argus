# 比較計算の呼出し内の準備

過去検証と重み探索では、各局面の条件の並びから作るビット列を
一回の計算内で準備する。組合せごとの編集距離は従来どおり計算する。
長い系列、空系列、同時発生、ハッシュ不能な条件の互換経路を保持する。

重み探索では、採用できる成分の組合せごとに重みと分母を準備する。
4成分の最大16通りだけを各候補方針で保持し、候補の組合せは保存しない。
足し合わせる順序、欠測成分の除外、重み0、閾値、同順位時の順序、
期間重複の除外、学習・確認・未使用期間の区切りは変更しない。

準備は呼出しをまたいで保持せず、入力や訂正が変われば作り直す。
内容キー、原本、保存した検証結果の照合と復旧条件は維持する。
Todayの順番とFUTURE MAPの最初のチャートは変更しない。
追加の取得・AI・時計・永続キャッシュは作らず、900秒の期限も維持する。

手元の同一入力・全文一致と速度測定、本番の通常実行の時間短縮、
過去の時間切れの原因解消は、それぞれ別に確認する。
