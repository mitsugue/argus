# 日経平均の引け更新（2026-10-06）

## 修復対象

従来は毎時7分・37分予定の全体収集の後段で指数と推計を取得し、
類似局面の保存応答にチャート用データも固定していた。
指数足の当日利用は16:00以降、画面の金額は朝の前日終値を優先していた。
終値を受信しても、全体収集・類似局面計算・画面の朝記録が更新を遅らせ得た。
これは実コードの原因であり、特定日の本番取得成功の証明ではない。

## 価格とPERの二段階

既存のサーバー内スケジューラーと重い処理の排他を使用する。
追加の全体収集・AI生成・立花ログインは行わない。

| 日本時間 | 対象 |
|---|---|
| 15:31 | 引け値の最初の確認 |
| 15:35・15:45 | 終値が未到着なら再確認 |
| 16:05 | 未到着の終値と当日推計の入力確認 |
| 18:05・19:05・20:05・21:05 | 未取得の項目だけ再確認 |

各枠一度だけ。価格と当日推計が揃えば後続枠は取得しない。
休日には取得せず、既存の全体収集は継続する。
他の重い処理が実行中なら排他を維持し、枠内の次の巡回で実行する。
サーバー停止・配信元遅延があるため、表は確認開始時刻であり配信完了保証ではない。

15:30のクロージング・オークションの直後に、取得元の市場時刻が引け以降で
日次足の終値と市場価格が一致する場合だけ、当日足を実受信時刻から使う。
15:29の価格や未来の市場時刻を終値としない。確定情報がない場合は
既存の16:00以降の再取得を待つ。取得済みの途中足を時刻だけで確定足へ変えない。
参照：[JPX売買立会時間](https://www.jpx.co.jp/equities/trading/domestic/01.html)。

推計は既存の時価総額加重方式と保存先を使用し、引け後枠では当日1日分だけを
取得する。10年分の補完を引け速報へ混ぜない。J-Quantsの入力の実到着を確認し、
公表前の入力を捏造しない。公式PERの19時頃という案内はこの推計の公表時刻ではない。

## 表示・事前記録・履歴

青い終値、水平の終値、参考予測との差は同じ最新の完了足を使う。
引け後の価格の目盛りは最新終値と利用できる推計EPSから投影する。
当日EPSが未到着ならEPSの日付と入力待ちを表示し、終値だけを先に更新する。
朝の固定記録、候補の事前条件、過去のPER線、採点規則は変更しない。
表示投影を朝の事前登録として保存しない。

類似局面の計算時刻・署名は元のまま、その保存応答に同梱する描画層だけを
現在のキャッシュから作る。画面GETから外部取得・全類似局面再計算を開始しない。
画面の既存10分定期確認と手動全再読込は維持する。

実装・手元検査・公開検査・本番配信・翌営業日の15:31実受信は別々に判定する。
特定日の価格・時刻・保存読み戻しは、認証された読み取りで確認する。
