# 推計EPSの入力不足と受領訂正

現行の時価総額加重方式を維持する。欠測の銘柄を両合計から除いた推計は、
正のEPSが計算できても完成した入力として表示・採点に使わない。
利益欠測件数と使用した時価総額の割合も受入条件に含める。
これらを持たない旧記録は範囲不明として互換読取を残すが、新規受領には使わない。

株価から予想・実績EPSを利益へ換算する際、PER×EPSとPBR×BPSで株価を得られない場合に限り、
同一銘柄・同一取引日の調整前終値を既存の日足取得から接続する。
赤字・明示されたゼロを保持し、EPS自体の欠測はゼロや前日の値で埋めない。
株価APIの時価総額は自己株を含むため、評価APIの時価総額欠測の代用にしない。
調整済み終値、他日付、優先株、重複した日足は補完に使わない。

日次の既存収集で対象日最大20件を維持し、最新日の優先と過去の日付の巡回を共存させる。
過去の巡回位置は同じ処理内の位置情報であり、取得時計や完了記録ではない。
日足による補完は1巡回につき最大1日、2ページ、各8秒の上限で行い、
GETや画面操作では取得しない。ページ途中の失敗・反復・上限到達は空として拒否する。
株価が得られても、全対象の利益・時価総額がそろうまで訂正を保存しない。

原版は既存のEPS原版表に保持する。完成した後の受領だけを、元のハッシュと
実受領時刻を持つ既存の訂正表へ追記し、同じ非公開バックアップ・復元経路で扱う。
日足補完には消費した正規化入力のハッシュ・日付・実受領を付す。
過去日の再取得は当時の公表・受領を証明せず、その区別を記録する。
過去の朝固定記録・候補・採点・旧署名は書き換えない。

構成数は対象日の公式変更履歴に合わせる。2021-12-29の除外と2022-01-05の採用の間を
機械的に225社へ増やさない。調査・隔離復元・配信・本番読戻しの受入は別に記録する。
