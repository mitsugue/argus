# 保存済みの会社決算予定

既存の共有銘柄一覧にある日本株・米国株の予定だけを、保存済み目標株価部品からEVENTSへ渡す。本人登録・一時追加銘柄を公開の一覧へ加えない。GETは既存保存の読取だけで、会社予定取得・価格取得・AIを始めない。

会社公表の予定と提供元の推定を区別する。会社予定はJ-Quantsの同一銘柄・日本時間・公表日・受領を照合する。推定はYahooの対象日または7日以内の範囲で、受領から7日超は採用しない。撤回・矛盾・未来受領・日付や出典の不一致を予定へ変えない。

米国の予定は米国の日付と夏冬時間を保つ。日付だけの予定に実際の公表時刻・結果・発表済み状態を付けない。日本では翌日でも米国の対象日が終わるまでは残す。同じ日付の複数社は別の予定IDで保持する。その他のイベント・48時間の直近結果の優先・Todayのカード順は変更しない。

金融原本の既存3読取には、実経過時間と当該スレッドのCPU時間だけを付ける。既存の観測器による待ち時間と各読取自体の時間を分け、対象・回数・検証・失敗判定・保存原本を変えない。CPU時計が利用できない時は不明のままとし0で補わない。新しいタイマーや計測用ジョブは作らない。

公開検査・実保存からの一覧投影・次の自然受領・本人端末は別に受け入れる。予定の接続を実績受領や有効な予測の証明へ流用しない。
