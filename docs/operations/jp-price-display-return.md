# 登録日本株の受信価格と表示

既存の立花PRICE接続で受信した価格を、既存の日本株価格GETへ添える。
GETは受信済みの状態を読むだけで、価格取得・AI・保存を開始しない。
本人認証、対象の登録保存先、単一セッション、10秒の一括取得、日次上限、
03〜06時禁止、エラー当日停止、注文無効は維持する。

画面の価格とリアルタイム判定を区別する。分精度の価格時刻を受信時刻や
秒単位の取引時刻に置き換えない。15秒以内の既存LIVE条件は不変。
受信した当日の有限価格は時刻付き参考として表示し、古い受信は保存価格、
閉場の値は市場クローズと示す。参考価格を判断の正本や確率に採用しない。
原版、朝の固定記録、予測、採点、分析の基準は変更しない。

表示中は既存の日本株価格タイマーだけを10秒へ切り替える。閉場・停止時は
従来間隔へ戻し、背景では取得しない。復帰時の一斉読取や本人確認を追加しない。
価格のために重いdecision-evidenceを10秒ごとに読む旧連動を外し、必要な
対象変更と既存の分析間隔を維持する。対象の異なる価格読取は各対象範囲だけを
更新し、遅い応答で新しい価格記録を巻き戻さない。

受信試験、コード検査、配信、通常運用での実受信、本人画面を別に受け入れる。
本番の有効化には既存の本人試験と利用記録、登録株の受信、鮮度、資源、停止と
ログアウトを確認する。短時間のメモリ検査を長期資源保証や旧失敗の修復にしない。
価格・銘柄・原応答・秘密・本人記録を公開検査へ持ち込まない。

配置時は試験用の明示対象を通常登録へ流用せず、既存の本人登録読取へ戻す。
既存の永続利用記録をそのまま接続し、使用回数や当日停止を初期化しない。
価格の既存ワーカーは本番の2GB環境内で一つだけ起動する。承認フラグと
対象設定の変更、自然受信、本人画面の受入はコード配信とは別に記録する。
