# 登録銘柄の説明入力の上限

所有者向けの入力は65,536バイト以内、保存レコードは既存の196,608バイト以内を維持する。
上限を超えた資料を切り捨てず、同一内容を参照で表せる場合だけ既存の保存形式内で小さくする。

通常の登録銘柄の説明では、財政の事実・根拠ID・出典・時点をそのまま保持する。
仮定計算専用の詳細な財政シナリオは、既存の市場見立てのIDと内容ハッシュへ結び付ける。
新しい保存先は作らない。明示的な財政仮定の計算は従来の完全な入力を使う。

前回の根拠を持つ新しい登録銘柄入力が上限を超えるときだけ、現在と完全一致する本文を
現在の根拠の位置で参照する。展開後の前回根拠全体のハッシュを保持し、順序と全項目を検査する。
異なる本文・数値・単位・時点・検証状態・反対材料は参照にせず全文を保持する。
選択した根拠IDの一覧も同じ入力から展開できる位置参照とハッシュで保存する。
展開できない参照、改変、曖昧なID、未知の形式は拒否する。収まらない場合は従来どおり保留する。

生成へ渡すときは完全な前回根拠と選択IDを復元し、既存の根拠・数値・種類・表示構成の検査を通す。
旧保存版の本文・識別ID・ハッシュは変更しない。新形式も同じ暗号化保存・全件復旧を使う。
過去の保有申告を新しい登録銘柄入力へ戻さない。閲覧から収集やAI生成を始めない。

通常巡回の登録数・保存数・現在方針の保存数・表示構成の受入数・固定の失敗分類だけを
既存の非公開診断へ渡す。診断の読取は記録済みの状態だけを返し、DB読取・市場取得・AIを追加しない。
本番の全登録への自然反映は、配信・模擬検査・隔離再生と分けて確認する。
