# 通常収集の固定診断

既存の本人専用 memory-attribution 読取に、直近の収集の開始・終了、同一プロセスの
前回終了、起動元、固定工程の開始と所要時間を追加する。収集の結果本文や対象銘柄は含めない。
現在実行への合流では元の起動元と前回終了を保持する。再起動直後の前回終了は不明のまま。

既存の研究状態には、実行中の固定対象、各対象の経過時間・スレッドCPU時間と、比較校正の状態を追加する。
REUSEDは利用可能な結果があり、当該呼出しの前後で校正キーが同じ場合。
CALCULATEDはキーが新しくなった場合、NOT_EVALUABLEは比較を評価できなかった場合。
校正ハッシュキーそのもの、価格、原本、所有者の記録は診断へ追加しない。

共有する入力準備を別の通常処理が実行中なら、収集側は既存処理へ合流する。
その待ち時間と、研究の実行時間は別に読む。時刻の対応がない工程を当該収集の原因としない。

GETから取得・生成・保存は開始しない。収集間隔・期限・単一実行、判断・検証・保存の
規則を変更しない。既存収集CLIのprivate-timing出力もv2の実行文脈を保持する。
終了後の固定CPU・工程・RSSの非公開読取は、同じ時間枠内で一回だけ行う。
最新の研究観測と収集スレッドのCPU帰属を分け、詳細は
`analog-calibration-scale-scope.md` の「チャートと収集後の照合」に従う。
Todayの順番とFUTURE MAPの最初のチャートは変更しない。
