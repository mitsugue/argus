# 2027年の公表済み米国指標日程

既存の確定日程表へ、公表済みのCPI・PPI・雇用統計とPCE・GDPを各12回追加する。公式の予定を実公表時刻や指標結果として扱わず、既存の米東部からUTC/日本時間への変換、45日窓、過去3日の保持、同日異種イベントの識別を維持する。

BLSは公式年次ページのWeb読取、BEAは公式年次ページのHTTP200原文を照合した。各予定に出典URL・確認時刻・根拠区分を付け、BEAだけ原文のハッシュを結ぶ。BLS直接HTTP403は保持し、Web読取を原HTTP本文へ変えない。両資料の更新表示を実HTTP公表時刻へ変えない。2026年の予定とその根拠時刻は書き換えない。

- BLS: https://www.bls.gov/schedule/2027/home.htm
- BEA: https://www.bea.gov/news/schedule/next-year

JOLTSの2027年分は公式確認先にまだ掲載を確認できないため、曜日や前年から補わない。日本統計全体の網羅も別の未確認として残す。新しい収集・タイマー・AI・保存経路・権限は追加しない。実際の受領と反応・自然保存の受入は発表後に既存経路で確認する。Todayのカード順とFUTURE MAPは変えない。
