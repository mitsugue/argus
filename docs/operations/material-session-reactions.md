# 材料発表後の営業日反応と既存受領根拠

類似局面の材料反応は、既存の現物日経履歴・公式営業日・macro保存記録だけを読んで計算する。
1/3/5営業日の終値参考は5/30/60分反応と別系列で、即時の発表前価格や因果関係、予測確率を示さない。
実公表時刻または独立した公式発表境界の根拠と受領を持つeventTimeEvidenceがない記録は保留する。
予定、旧releasedAt、HTTP Date/Last-Modified、受領時刻から実公表を補わない。
公式embargo境界の参考値を実HTTP公表時刻や当時の原本受領にしない。

現物の本人性・受領ハッシュ・利用時点・終了窓・途中営業日の有限値を確認し、代理、重複、途中穴、
未来受領を拒否する。後読みされた保存履歴の最も遅い受領を使い、過去cutoffへ戻さない。
材料入力が保留でも取得済みの価格チャートは維持する。件数不足と未検証を保持し、売買権限は付与しない。

比較の成績キャッシュは、可視価格内容、営業日、封印候補ID、重み、利用時点までの状態履歴で結び付ける。
同件数の材料や価格の訂正、受領変更を再検査対象にし、未来の未受領行だけの追加で成績を変えない。

既存BLSのNFP/CPI/PPI/JOLTS要求の復号済みHTTP本文ハッシュと解析JSONハッシュ、同一入力の実受領を
既存結果記録へ任意のsourceHttpReceiptとして結ぶ。追加の要求・AI・原本文やヘッダー・鍵の保存は行わない。
2値タプル、値、旧受領ハッシュ、改訂IDと改訂履歴は維持し、無効な任意根拠は既存の解析結果を消さない。
ハッシュ参照を原本文の読戻し、wireの保存、実公表時刻の証明にしない。
同じmacro保存・復元を使い、新しい収集・保存基盤や時計を作らない。

手元候補、公開両証明、配布版、本番自然受領・読戻し、固定期間の基準比較、本人端末を別に受け入れる。
当時の受領と全材料の原典が不足する履歴を10年検証済みとせず、準備済み6参考区間は再取得しない。
