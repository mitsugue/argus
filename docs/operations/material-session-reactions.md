# 材料発表後の営業日反応と既存受領根拠

類似局面の材料反応は、既存の現物日経履歴・公式営業日・macro保存記録だけを読んで計算する。
1/3/5営業日の終値参考は5/30/60分反応と別系列で、即時の発表前価格や因果関係、予測確率を示さない。
実公表時刻または独立した公式発表境界の根拠と受領を持つeventTimeEvidenceがない記録は保留する。
予定、旧releasedAt、HTTP Date/Last-Modified、受領時刻から実公表を補わない。
公式embargo境界の参考値を実HTTP公表時刻や当時の原本受領にしない。

現物の本人性・受領ハッシュ・利用時点・終了窓・途中営業日の有限値を確認し、代理、重複、途中穴、
未来受領を拒否する。後読みされた保存履歴の最も遅い受領を使い、過去cutoffへ戻さない。
材料入力が保留でも取得済みの価格チャートは維持する。件数不足と未検証を保持し、売買権限は付与しない。

比較の成績キャッシュは、可視価格内容、営業日、封印候補ID、重み、利用時点までの状態履歴で結び付ける。
同件数の材料や価格の訂正、受領変更を再検査対象にし、未来の未受領行だけの追加で成績を変えない。

既存BLSのNFP/CPI/PPI/JOLTS要求の復号済みHTTP本文ハッシュと解析JSONハッシュ、同一入力の実受領を
既存結果記録へ任意のsourceHttpReceiptとして結ぶ。追加の要求・AI・原本文やヘッダー・鍵の保存は行わない。
2値タプル、値、旧受領ハッシュ、改訂IDと改訂履歴は維持し、無効な任意根拠は既存の解析結果を消さない。
ハッシュ参照を原本文の読戻し、wireの保存、実公表時刻の証明にしない。
同じmacro保存・復元を使い、新しい収集・保存基盤や時計を作らない。

手元候補、公開両証明、配布版、本番自然受領・読戻し、固定期間の基準比較、本人端末を別に受け入れる。
当時の受領と全材料の原典が不足する履歴を10年検証済みとせず、準備済み6参考区間は再取得しない。

## 過去の発表の研究用反応（2026-10-18・オーナー決定）

BLSの公表文書は自動の読み取りを拒否する（手元とGitHub Actionsの両方から403、2026-10-18確認）。
そのため上の「実公表時刻の根拠」は過去の発表には作れない。オーナー決定により、上とは別の種類の
根拠として次を持つ。上の決まり（予定や受領時刻で実公表を補わない）は変えない。

- 発表日: セントルイス連銀の発表日の記録（FRED release/dates。雇用統計50・CPI 10・PPI 46・JOLTS 192）。
  延期された回も実際の日付で残る。1日1回、既存の収集で4回だけ読み、鍵は要求にだけ使い保存しない。
- 時刻: BLSの決まった発表時刻（雇用統計・CPI・PPIは東部時間8時30分、JOLTSは10時）。
  `timeBasis=ARCHIVED_RELEASE_DATE_FIXED_TIME_RULE`。実公表時刻の確認は常に未確認のまま。
- 時刻の誤差が結果を変えない理由: 反応は発表直前の東京の終値から後の終値までで測る。米国の同じ日付の
  午前2時30分〜深夜の発表は、どの時刻でも同じ終値の組になる。結果を決めるのは日付。
- 利用時点: 窓の最後の終値が出た時点で知り得たものとする（`RESEARCH_KNOWN_AT_ENDPOINT_CLOSE`）。
  当時の受領ではない。発表時刻の根拠を持つ記録の反応が同じ指標・同じ日にあれば、そちらを優先する。
- 使うかどうか: 反応を含めた候補と含めない候補で過去検証を同じ日付で回し、評価日の前4分の3で
  5営業日後の方向一致率が上がり、しかも同じ日付で「片方だけが当たった日」の数の差が偶然では
  説明しにくい（片側5%未満）時だけ候補選びに含める（各50件以上）。一致率が少し上がるだけでは、
  でたらめな模擬データでも採用されたため（2026-10-18の試運転）。残り4分の1は両方の成績を
  表示するだけで判断に使わない。予測の確率にはしない。結果は画面の比較の説明に件数と並べて出す。

## FOMCと日銀の決定(2026-10-19)

- 種類: `fomc`、`boj`。日付は `jp_market_historical_releases.FOMC_DECISION_DAYS` と
  `BOJ_DECISION_DAYS`(2016-01〜2026-12、各会合の最終日)。原典は federalreserve.gov の
  fomccalendars.htm と fomchistorical<年>.htm、boj.or.jp の mpmsche_minu/past.htm と index.htm。
- 対象は定例会合と、2020年3月3日・15日の臨時利下げ。政策の声明がない書面決議は入れない。
- 時刻はどちらも規則で、実公表時刻の確認ではない(`actualPublicationTimeVerified=false`)。
- 外部への取得はしない。表の内容のハッシュを `sourceSha256` とする。
- 新しい年の日程は、各中央銀行の公表を確かめてから表に足す。
