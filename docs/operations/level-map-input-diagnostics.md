# EPS取得の本人向け診断

既存の本人診断 `GET /api/argus/admin/memory-attribution?level-map-inputs=1`
は、実行中のEPS取得で選んだ日付と結果を返す。本人認証を必須とし、
指定なしの応答は変えない。この読取は取得、AI生成、保存を開始しない。

過去分は既存の1巡20日付、当日分は1日付の選択をそのまま記録する。
カーソルの前後、選択済み日付、取得値なし、入力不足、不正な推計値、
原版保存、訂正保存、既存保存の区別を確認できる。入力不足件数は利益と
時価総額を分け、未観測値を0にしない。選択したが処理前の行も保存成功に
しない。株価、銘柄、原応答、自由なエラー本文、秘密は返さない。

記録は実行中プロセスの直近の過去分と当日分だけであり、当日分の実行で
過去分を上書きしない。再起動後の未観測や途中の読取を、永続した取得履歴
や全期間の成功証明にしない。既存の保存・復元経路を増やさない。

診断の追加だけでは歴史的入力不足の修復完了にはならない。自然取得後の
実カーソルと結果を読み、必要な入力を特定してから既存経路で修復する。
元の推計値、訂正との結合、受領時刻、朝の固定記録、採点、数式、閾値は
変更しない。日足補完の1日付・2ページ・8秒制限も維持する。後取得を
当時の受領や公表の証明にしない。
