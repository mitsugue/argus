# 非公開検査記録の保存競合

Contents APIの409を受けた時だけ、同じ保存先のmain上の内容を読み直す。
同一内容なら読戻し一致として扱い、別内容なら変更せず停止する。
未作成の404を確認できた時に限り、同じ内容の作成を1回だけ行う。
更新用shaは付けず、既存の記録・失敗した試行・別試行の記録を上書きしない。

確認と再作成は元の1ファイル60秒以内に含める。2回目の競合、認証・権限・
レート上限・提供元失敗では停止する。公開ログは固定の分類だけで、応答本文・
保存内容・鍵を出さない。既存の最大20ファイル、8MiB/ファイル、非公開保存先、
試行別パスは維持する。収集・AIの再実行や新しい保存基盤は追加しない。

GitHub公式仕様: https://docs.github.com/en/rest/repos/contents#create-or-update-file-contents
409は競合である。元失敗のHTTP本文を読んでいない場合、競合の内部原因まで
確定したとは扱わない。保存できたファイルと未保存のファイルを区別する。
