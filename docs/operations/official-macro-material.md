# 重要指標の結果と今日の見立て

受領済みの重要な公式結果は、ニュースメールの有無に依存せず、既存のイベント記録から
見立ての先頭の根拠とニュースへ渡す。発表予定と実受領の両方が利用時点以前であることを
必要とし、公表瞬間が未確認なら受領時刻で代用しない。現在欄は発表予定から48時間、
既存の履歴欄は7日以内。再取得や訂正で新着期間を延長しない。

重要結果の独立した枠をAI見立ての上へ置かず、イベント欄の先頭で結果・市場予想比較・報道の背景を読む。
発表後48時間の重要イベントを、未発表の予定より先に表示する。以後は既存の履歴順へ戻す。
次の自然生成では、先頭の公式結果への参照が見立て・理由にない回答を既存の1回の
訂正対象とする。生成待ち・失敗でも公式結果は隠さず、旧本文の時点や履歴を変更しない。
重要結果の新受領・訂正は通常の時間内再利用から除外し、単なる読取時計では再生成しない。

公式結果の重要性を、市場横断ショックや日経下落の因果関係の確定と混同しない。
市場予想差は未受領なら未確認。前年比の前回比較は予想比較ではなく、波及経路は推論。
元のイベント原本・事前見立て・訂正・保存先は不変で、表示のための別保存・外部取得・
AI起動・通知送信は追加しない。売買権限も与えない。

再配信後の結果読戻しは既存のニュース巡回の先頭と見立ての定期処理で行う。
ニュースメールの受信完了や利用者のイベント欄の開閉に依存させない。メール未設定でも
見立ての定期処理から同じ一度限りの復元を使用する。表示GETは復元・外部取得・AIを
開始せず、元の受領時刻・原版・訂正と既存の保存先を維持する。

イベントの関連報道は既存の受領ニュースの短い分析と、許可した公開見出しだけを同じ
発表窓へ結合する。予想超過という報道を公式の予想値や当時保存した予想へ変更しない。
原油等による物価押上げ、政策金利の警戒、株安の記述の有無を別に検査する。報道上の
説明を因果関係の実証にせず、利上げ懸念と実際の長期金利上昇を区別する。記事不足は
表示し、見出しだけで本文を読んだことにしない。新しい重要報道は次の通常の事後分析へ
渡し、内容ダイジェストを結合して旧説明は訂正履歴に残す。表示GETはAIを起動しない。

今回の原油・CPI・利上げ警戒・株安の経路監査は、一般のイベント説明と区別する。
別の指標や逆方向の相場へ同じ説明を当てはめない。自然生成時に採用した短い報道根拠と
そのダイジェストは既存の事後分析記録へ保存し、後の新着記事と混同しない。

現在位置は同じ受領済みの公式結果と関連報道を既存テーマ記憶へ渡す。関連報道は統合AIの
根拠にも渡し、新内容・訂正は次の定期生成で旧版の時間内再利用から除く。記事を実測・
因果関係の確定へ変えず、異なる時点の古い反応で最新報道を隠さない。
見立ての履歴へ同時点の現在位置の表示用投影も保存する。既存履歴に含まれない項目を
後から補造・再署名しない。旧保存版や読取失敗は欄を消さず状態を明示する。
Watchlistタップは同じタブの再選択もスクロール先頭へ戻す。画面の再マウントや入力・
銘柄状態の消去、追加API読取は行わない。
