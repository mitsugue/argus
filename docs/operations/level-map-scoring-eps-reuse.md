# 採点内の前日EPS参照

入力準備の実スレッドで、採点の移動PER線が同じ営業日の前日EPSを繰り返し全走査する位置を確認した。
一回の `score_records` だけで、その日の参照結果を再利用する。空の結果もその呼出し内だけ保持し、
次の採点には持ち越さない。元のEPS・朝固定記録・株価・採点結果を変更しない。

厳密な前日、有限値、ゼロの除外、同日・未来値の不採用、停止・突破・到達・比較基準の規則を維持する。
ネットワーク・保存・AI・時計・権限を増やさず、FUTURE MAPのチャートのコードは変更しない。

保存済み株価と明示した合成EPS/朝記録で、旧処理との全文一致と全走査の減少を隔離照合する。
この合成入力の所要時間は、本番全体や過去の時間切れの同入力根因修復を証明しない。
配信後の本番処理時間と自然巡回は別に受け入れる。
