# 個別説明の保存待ち回答

ローカルの保存または読戻しが失敗すると、生成済みの回答は同じプロセスの
既存メモリへ保持され、要求は未完了として残る。表示の読取だけでは保存しない。
従来の明示保存に加え、既存30秒巡回が次の生成より先に保持中の1件を保存する。
新しい巡回時計・生成・再解析・提供元への再試行は追加しない。

本文・入力・提供元の受領・試行数・費用・完了時刻を変えず、保存後の全結果と
元の保持内容が一致してからメモリの保留を外す。保存済みの別内容は上書きしない。
失敗時は保持を続け、その巡回では新しい生成を始めない。不合格・未取得の
結果も元の状態で保存し、成功へ変更しない。

既存の本人診断には未保存件数と固定の保存状態だけを渡す。回答本文・識別子・
銘柄・エラーの自由文は診断へ出さない。過去の保存形式・ダイジェストは不変。
再起動後に失われた未保存回答を復元済みとして作らず、途中中断の履歴を残す。

配信前に、現在のプロセスが保持している既存回答を既存の状態確認・明示保存で
保全する。本番で同じ保存待ちが観測されたか、通常巡回で保存と後続更新が
進んだかは、手元の再現・製品証明と区別して受け入れる。
