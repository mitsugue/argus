# 手入力PERと発表後イベント

2026-10-15の本人依頼。実装と配信・実入力受入は別に記録する。

## 本人ログインと操作権限の区別

新しいnonceが応答で照合できれば、外側の本人セッション確認は通過している。
その後の操作別401（別の運用資格が必要な操作）を、ログイン失効へ変換しない。
操作そのものは拒否したまま。有効な管理資格と本人資格が併記された場合も、
管理権限を本人資格に置き換えず、存在する本人セッションだけ照合してnonceを返す。
24時間期限、専用session確認の失効・取消・ログアウト、成功応答のnonce検査は維持。
Cookieの寿命や保存先、本人確認の暗号・権限を増やさない。
この不具合は合成入力で再現したもので、本人iPhoneの反復Face IDの原因一致は未確認。

## 手入力

Todayの価格の目盛り直下に「今週の加重平均を書き写す」を置く。
日経平均プロフィルのPERへのリンクと、対象日・予想PERの加重平均を入力する。
指数ベースとの取り違えを明示し、同日推計との差15%以上は再確認を要する。
同日終値と完全な推計EPSが保存されていなければ保存を保留する。

値は本人セッション専用の既存owner-auth経路で受け、同じ非公開SQLiteに保持。
既存の自然巡回で、補正前後のEPS・PERを一組の別記録として保持する。
公開ルート・ログ・診断に入力PER、指数終値、元EPS、補正比を含めない。
入力のGETは状態と対象日のみ。市場取得・AI生成は起動しない。
補正比は同日終値÷入力PER÷未補正EPS。入力時刻以降、入力した日本時間の日付
以降の表示用推計にだけ適用する。以前の線、朝の固定記録、候補、採点、
警戒条件の検証系列は書き換えない。補正有無・最終入力日を表示し、10営業日超は警告。
補正を含む比較応答は端末の平文localStorageに保存しない。

週の最終営業日16:30以降、未入力なら案内を表示し続ける。初回も表示する。
入力後は閉じ、変更・削除はいつでも操作できる。削除は現用値を消して補正を停止し、
旧遠隔版が復旧で復活しないよう版番号を進めた空状態を残す。
バックアップの履歴版そのものの削除は行わない。

既存level-mapバックアップの同じ接続・期限・非公開保存先で現用状態をCAS保存し
読戻す。40書込み枠のうち1件をこの状態に割り当てる。公開属性を確認した保存先
には書かない。読取・本人入力POSTから同期を起動せず、既存の自然巡回で行う。
owner-authの既存オフライン復旧も新テーブルを保持し、セッションは復元しない。
旧DBには起動時にテーブルを追加するだけで、登録・認証・旧履歴を変更しない。
入力欄配信後の本人実入力、自然非公開保存・独立復元は別受入。

## イベント

時刻が確認でき、フィードが発表済みとするイベントは、発表後48時間を
Todayイベントブロックの先頭に表示する。新しい順。同日の日付だけでは
発表時刻を推測せず、未来時刻を先頭へ昇格しない。48時間後は過去7日の結果へ
移し、今後45日の予定も維持する。

初期表示は結果・照合・実測・判断・必要なら次の確認。
一般説明や事前の長文、分析全文、定義・取得時刻は詳細に保持する。
既存の文の途中を切って結論を作らない。実測は発表直前基準の検証済み数値だけ。
比較不能な市場を0や現在値で補わない。市場予想未接続の数値サプライズを採点せず、
条件付きシナリオの照合と分ける。今後の通常事後生成にも80文字・1文の出力指示を
適用する。表示を測るための追加生成は行わない。
原版・訂正・事前シナリオ・保存価格窓は不変。表示用の時刻再検証を別項目へ投影する。
