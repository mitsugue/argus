# 過去特徴量の再計算内での価格検査の共用

初回の過去再計算では、各日付で同じ価格行の時点検査と内容ハッシュを作り直していた。1回の `build_feature_history` の中だけ、元の `point_in_time_rows` で受け入れた価格行の所有コピーと検査情報を共用する。通常の1時点更新は従来の経路を使う。

公表・受領時刻、観測日、訂正番号、同一訂正の内容矛盾は、各日付の従来の価格窓を適用してから判定する。後日訂正を過去へ混ぜず、窓外の矛盾を窓内の失敗へ移さない。価格以外の信用統計等の監査件数と証明は従来どおり計算する。

結果は毎回所有コピーを返し、元入力・他の日付・次の再計算へ変更が漏れない。共用情報は計算終了で解放し、永続保存・全体キャッシュ・新しい収集経路は追加しない。特徴量・条件・出典・参照ハッシュ・履歴の版を含む全出力と、既存の手法指紋の一致を検査する。

手元の合成入力による速度差を本番の削減率にはしない。既存の収集診断で、配信後の実処理時間・処理位置・保存結果を別に確認する。900秒の期限、再試行回数、AI、判定式、予測・注文権限は変更しない。
