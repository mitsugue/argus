# 比較対象日の業種分類

日付指定なしの銘柄一覧は、休業日には翌営業日分を返す。比較期間の末日より
先の分類を拒む規則は維持し、既存の日足巡回で対象日を指定して取得する。
仕様原典: https://jpx-jquants.com/ja/spec/eq-master

取得対象日は価格と分類の保存済み入力から決め、AIの説明や判断を取得の権威にしない。
現在の銘柄検索は従来の一覧を使う。比較用は同じマスタ経路と既存のメモリ領域で、
価格系列で実際に比較できる末日と、直前に保存された分類の適用日の最大2版だけを保持する。
各版は最大6,000銘柄コード（末尾の異なる優先株を除く）、2MiB/ページ、全要求日合計40ページ以内。
日足巡回の150秒に含め、成功時24時間の控えと既存30分巡回を共用する。
価格や画面の読取は外部取得・AIを起動しない。新しい保存先や定期実行は作らない。

全ページの受領と適用日一致を確認してから版を公開する。部分応答、重複、
別日付、未終了のページ列は不採用とし、元の受領時刻を付けた前の版を残す。
優先株の末尾コードを普通株へ混ぜず、不明な業種を作らない。
内容ハッシュは正規化した分類一覧のもの。提供元のHTTP原本文や当時保存済みの
原本の証明ではない。後取得の受領を過去の日付へ戻さない。

共通の価格比較は実際に比較できた末日の分類を選ぶ。登録銘柄の説明も、
その説明に封印した期間の分類だけを既存キャッシュから読む。
元の指数・業種ETFの定義、騰落式、受領cutoff、引用検査と売買無効は維持する。
既存の公開サンプルと個人の登録を混ぜず、共有保存へ登録銘柄を追加しない。

既存の共有キャッシュ保存形式は変更しない。旧版と過去の説明を読み続けられる。
配信後は自然取得の分類日、同じ期間の指数・業種ETF・個別株、保存された説明の
引用を別々に照合する。配信だけで本番の比較接続や旧版全体を完了としない。
