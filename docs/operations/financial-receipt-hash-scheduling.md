# 金融受領のハッシュ検査と同時処理

受領範囲の同一性確認は、これまでと同じ全バイトを同じSHA-256へ渡す。受領本文、正規化した受領、原本の三箇所で、最大2047バイトずつ渡すだけとし、検査の回数・出力・例外・利用時点は変えない。署名・ハッシュ・原本・保存版の再作成はしない。

Python 3.12は2048バイト以上の一括ハッシュでGILを解放する。別の重いPython処理が同時に走ると、短い検証の反復でもそのたびに処理へ戻る待ちが生じる。通常のPythonの切替間隔は変更せず、処理全体の排他や優先権も追加しない。分割した入力の連結と元入力が完全一致し、標準SHA-256と同じ結果になることを検査する。

出典: https://docs.python.org/3.12/library/hashlib.html

隔離環境の同時処理実験を本番の同一入力原因や改善率へ広げない。本番の既存金融検証時間/当該CPU時間で別に受け入れる。元1046秒/別240秒の事案、メモリ根因、正式資源は別条件として残す。取得・AI・タイマー・保存先・認証・権限の追加はない。
