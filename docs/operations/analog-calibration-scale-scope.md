# 過去検証の入力範囲と再利用

過去の類似局面の選択、年初時点の尺度、価格、公式営業日、材料反応、
現在の尺度に変更があれば検証を更新する。候補の原入力IDと全内容の照合を維持する。

年ごとの尺度は、その年の1月1日より前に受領した行だけを使う。
キャッシュも全対象年の尺度へ入る行を全改訂込みで結び付ける。
最新対象年の年初より後の受領変更は、それだけで過去検証を再実行しない。
現在の尺度や封印した過去局面が変われば従来どおり再実行する。

過去検証の式、閾値、評価期間、材料採用比較、現在の表示入力、保存原本は変えない。
校正キーの内部スキーマを更新し、従来の加速用キーを新しいキーとして流用しない。
保存形式は既存のものを使う。Todayの順番とFUTURE MAPの最初のチャートは変更しない。

手元の回帰確認と、本番の自然巡回での所要時間・再利用確認は別に受け入れる。
