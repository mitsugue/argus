## 個別説明（owner_dialogue）の作り直しの回数（2026-11-10）

実測（ai-usage-report）で 11/9 の owner_dialogue は 1,475 回・入力 2,714 万トークン。統合AIの見立ての新しい版（平日 14〜25 版）が出るたびに、登録銘柄すべての説明が書き直されていた。

**2026-11-10 同じ日の追記（オーナー「AIの見立てはボタンを押した時だけ」「週に一度も個別株のAI見立ては要りません」）**: 本番では銘柄ごとの説明を自動では作らない（`manual_overviews=True`）。銘柄の画面の「AIの見立てを作る」ボタン（`action: overviewGenerate`）を押した時に、その1銘柄だけ作る。材料が前と同じなら作らずに前の説明を返す。1銘柄1日3回まで。保存した説明を読むだけではAIを呼ばない。下の時刻の決まりは、自動で作る設定の時だけ使う。

`argus_overview_refresh.py` で、保存済みの説明を書き直すのは次の時だけにした。

- 金曜 16:00（日本時間・その週の最後の引けの版の後）を過ぎて、まだその週に書き直していない時（週1回。同じ日にオーナーが「平日1回」より「週1回」を選んだ）
- その銘柄自身の材料（保存決算・関連報道・選んだ公式発表）が変わり、前の説明から1時間以上たった時
- 1銘柄あたり1日3回まで（却下された回答を、新しい版のたびに試し直さない）

市場の材料は説明の中に残る。市場の版が変わっただけでは書き直さない。初めて登録した銘柄は従来どおりすぐ作る。
