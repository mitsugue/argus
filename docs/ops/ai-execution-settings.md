## 個別説明（owner_dialogue）の作り直しの回数（2026-11-10）

実測（ai-usage-report）で 11/9 の owner_dialogue は 1,475 回・入力 2,714 万トークン。統合AIの見立ての新しい版（平日 14〜25 版）が出るたびに、登録銘柄すべての説明が書き直されていた。

**2026-11-10 同じ日の追記（オーナー「AIの見立てはボタンを押した時だけ」「週に一度も個別株のAI見立ては要りません」）**: 本番では銘柄ごとの説明を自動では作らない（`manual_overviews=True`）。銘柄の画面の「AIの見立てを作る」ボタン（`action: overviewGenerate`）を押した時に、その1銘柄だけ作る。材料が前と同じなら作らずに前の説明を返す。1銘柄1日3回まで。保存した説明を読むだけではAIを呼ばない。下の時刻の決まりは、自動で作る設定の時だけ使う。

`argus_overview_refresh.py` で、保存済みの説明を書き直すのは次の時だけにした。

- 金曜 16:00（日本時間・その週の最後の引けの版の後）を過ぎて、まだその週に書き直していない時（週1回。同じ日にオーナーが「平日1回」より「週1回」を選んだ）
- その銘柄自身の材料（保存決算・関連報道・選んだ公式発表）が変わり、前の説明から1時間以上たった時
- 1銘柄あたり1日3回まで（却下された回答を、新しい版のたびに試し直さない）

市場の材料は説明の中に残る。市場の版が変わっただけでは書き直さない。初めて登録した銘柄は従来どおりすぐ作る。

## 統合AIの見立てを作る時刻（2026-11-10 オーナー「1日3回にする」「10/17から3つ」）

平日（東京の取引日）は 8:00・12:00・15:45（日本時間）の3回だけ作る（`argus_brief_schedule.py`・`brief-schedule-v2`）。2026-10-17 に決めた11の時刻（7・8・9:15・10・12・13・15:45・17・20・22・24時）から3つを選んだ。土日祝は 8:00 と 20:00 のまま。重要な発表（CPI・PPI・PCE・NFP・JOLTS・GDP・FOMC・BOJ の結果を受け取った時）の直後は、これまでどおり1日3回まで追加する。

## 自動の処理は OpenAI の割引の窓口（Flex）で（2026-11-11 オーナー【AIを割引の窓口で】「始める」）

同じモデルのまま、急がない処理の窓口（`service_tier="flex"`・公式の値段の表で通常の半額）に送る（`argus_openai_tier.py`）。

- 対象: 統合AIの見立て（`market_brief`）・ニュース読み（`news_intel`）・平日のAI判定（`ai_judgment`）・発表の分析（`event_analysis`）・市場の位置の確認（`market_position_check`）。
- 対象外: 銘柄の画面のボタン（`owner_dialogue`。押した人を待たせない）・調査・試験の呼び出し。
- 返事が遅いので待ち時間の上限を300秒にした。見立ては重い処理の枠を使うが、作る時刻（8:00・12:00・15:45）は取引時間の外。
- 「空きがない」の断り（429・料金はかからない）の時だけ、同じ依頼を通常の窓口で1回だけ送り直す。窓口が受け付けない（400・料金はかからない）時は、そのモデルと道具の組を再起動まで通常にする。時間切れ・利用上限・回数の上限・理由の分からない429は送り直さない（受け付け済みで料金がかかっている可能性があるため）。
- 費用の見積もりは、OpenAI が実際に使った窓口（応答の `service_tier`）で計算する。
- 止める時は Render の環境変数 `ARGUS_OPENAI_FLEX=0`（秘密の値ではない）。診断の `openaiServiceTier` に、頼んだ回数・割引で答えた回数・通常へ回した回数と理由が出る。
